# IntelliLearn Frontend

React-based frontend for the IntelliLearn AI-powered learning path system.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The app will run on http://localhost:3000

## Features

- Modern chat interface
- Real-time messaging with AI agent
- Resume upload (PDF)
- Skill extraction and display
- Session state management
- Responsive design

## Tech Stack

- React 18
- Vite
- Axios
- Lucide React (icons)
